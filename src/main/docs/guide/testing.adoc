= Testing with Pytest

Pyronaut runs Python tests through pytest and reports them through the JUnit Platform.
Use `pyronaut test` instead of invoking pytest directly when tests need the Micronaut classpath, processed sources, test resources, or `MicronautTest`.

Add the pytest integration to the test scope:

[source,toml]
----
[tool.pyronaut.dependencies]
test = [
  "io.micronaut.pyronaut:micronaut-pyronaut-pytest",
  "io.micronaut.test:micronaut-test-junit5"
]
----

Run all tests:

[source,bash]
----
pyronaut test
----

VS Code's Python pytest support invokes pytest directly and is not suitable for Micronaut-backed Pyronaut tests.
Use the Pyronaut VS Code Test Explorer extension when running these tests from VS Code.
See xref:configuration/vscodeExtension.adoc[].

`pyronaut test` performs install and process preflight, runs configuration validation for the `test` scenario, starts test resources by default, and delegates test discovery to pytest. Use `--disable-test-resources` for direct source tests when test resources are not needed.

== Direct JUnit 5 Tests

For a small application, Java or Python sources can be tested without a project manifest. The application sources come before `--`; JUnit 5 test sources come after it:

[source,bash]
----
pyronaut test Foo.java -- FooTest.java
pyronaut test Foo.py -- FooTest.py
pyronaut test -t Foo.java -- *Test.java
----

Direct tests are compiled and executed in-memory through the JUnit Platform. Python tests can use `@MicronautTest` and `org.junit.jupiter.api.Test` in the same style as the Python test suite. Direct Java runs disable Python runtime infrastructure automatically; Python remains enabled by default for Python tests.

Use `--continuous` or `-t` to rerun direct tests when application or test sources change. The console prints execution progress and a final test summary.

Use `--report` to write JUnit XML and HTML reports. The default location is
`__pyronaut__/reports/tests`; pass a directory after the option to choose another
location:

[source,bash]
----
pyronaut test --report Foo.java -- FooTest.java
pyronaut test --report build/test-reports Foo.java -- FooTest.java
----

== Project Test Discovery

Python tests are discovered from the configured `python-test` source directory.
The default directory is `tests`.

[source,toml]
----
[tool.pyronaut.sources]
python-test = "tests"
----

Use `--tests` for selector-style filtering:

[source,bash]
----
pyronaut test --tests tests/test_controller.py::test_index
----

== Reports

Test reports are written under:

[source,text]
----
__pyronaut__/reports/tests/
----

Important files include:

- `index.html`
- `junit.xml`
- `.pyronaut-last-nodeid.txt`
- `events.ndjson`

== Context Tests

Use `MicronautTest` when a pytest needs a Micronaut `ApplicationContext`, injected beans, an `EmbeddedServer`, or configuration properties.
Use `pyronaut.requests` or the `requests` shim for HTTP tests against the embedded server.
