= Pyronaut Project Generator

The Pyronaut project generator builds a minimal runnable Python application with Micronaut ProjectGen.
It is used by `pyronaut create`, and it can also be embedded by tools that consume Micronaut ProjectGen directly.

The generator is provided by the following dependency:

dependency:micronaut-pyronaut-projectgen[groupId=io.micronaut.pyronaut]

Create a project with:

[source,bash]
----
pyronaut create demo
pyronaut create demo --features data-jdbc,mysql,json-schema,test-resources
pyronaut create --list-features
----

Generated projects use the standard Pyronaut layout:

* `pyproject.toml`
* `config/application.toml`
* `src/main.py`
* `src/<module>/controller.py`
* `src/<module>/__init__.py`
* `tests/test_<module>.py`
* `tests-config/application-test.toml`
* `.agents/skills/pyronaut-project/SKILL.md`
* `.agents/skills/pyronaut-cli/SKILL.md`
* `.agents/skills/pyronaut-coding/SKILL.md`
* `.gitignore`

The default application includes a simple HTTP controller, Logback-backed Python logging setup, pytest integration, and generated agent guidance for local Pyronaut workflows.
Python, TOML configuration, and pytest are fixed defaults. There are no language, build tool, or Java test framework switches for Pyronaut projects.

After generation, run:

[source,bash]
----
cd demo
pyronaut install
pyronaut process
pyronaut test
pyronaut dev
----

Pyronaut reuses compatible Micronaut starter features when their dependency and configuration behavior applies to Python projects.
Feature contributions are translated into `pyproject.toml` dependency arrays and Pyronaut TOML configuration files instead of Gradle or Maven build files.
