= Configuration and Build Setup

Pyronaut project configuration is split between two TOML files:

- `pyproject.toml` describes the Python package, Pyronaut source layout, Java dependencies, repositories, build defaults, validation settings, IDE support, toolchains, and test resources.
- `config/application.toml` contains Micronaut application configuration loaded at runtime.

Most build and lifecycle settings are under `[tool.pyronaut]`.
Pyronaut's generated schema uses canonical kebab-case keys, while some older camelCase aliases are still accepted for compatibility.

Run `pyronaut install` after changing `pyproject.toml` to refresh dependency manifests, JSON schemas, and Python IDE stubs used by later commands.

Use `pyronaut validate-config` when changing application configuration or dependency sets.
It validates Micronaut configuration for run, test, or production scenarios and writes reports under `__pyronaut__/reports/config-validation`.

== Choose your setup

* *New Pyronaut project:* Start with <<pyproject,Configuring `pyproject.toml`>>, then add dependencies with
  <<dependencies,Installing Python and Micronaut Dependencies>> and application settings with
  <<appConfig,Application Configuration with `application.toml`>>. Use <<validateConfig,Configuration Validation>> before
  deployment.
* *Existing Maven or Gradle project:* Start with <<mavenGradle,Using Maven and Gradle Projects>> to connect the existing
  build, then use the dependency and application configuration pages as needed.
* *Direct-source application:* Use <<directSourceDeclarations,Declaring Direct Source Dependencies>> when the application
  does not have a `pyproject.toml`.
* *Custom repositories or a proxy:* Read <<mavenRepositories,Configuring Maven Repositories>> and
  <<proxyConfig,Proxy Configuration>> when dependency resolution needs non-default network settings.
* *Editor support:* Run `pyronaut install`, then follow <<ideSetup,IDE Setup for VS Code and PyCharm>>. Use the
  <<vscodeExtension,VS Code Test Explorer Extension>> page when tests must run through `pyronaut test`.
