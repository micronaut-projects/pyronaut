= IDE Setup for VS Code and PyCharm

`pyronaut install` generates editor support from the resolved runtime and test classpaths.
This gives Python editors stubs for Java-backed APIs such as Micronaut annotations and Jakarta injection types.

Generated editor files include:

- `__pyronaut__/schemas/pyronaut-pyproject.schema.json`
- `__pyronaut__/schemas/micronaut-application.schema.json` (the `#:schema` directive is only added to `application.toml` when that file exists)
- `__pyronaut__/ide-stubs`, including a `pyronaut/<facade>/__init__.pyi` stub for each <<facades,Pyronaut facade>> and a `FACADES.md` index of the facades
- `__pyronaut__/resolved-editor-artifacts.json`
- `__pyronaut__/reports/editor-stubs/stub-generation-report.txt`

`pyronaut install` prepends a Taplo schema directive to `pyproject.toml` and to `application.toml` when those files do not already have user-managed schema directives.

== Configure stub generation

[source,toml]
----
[tool.pyronaut.ide-stubs]
enabled = true
ide = "vscode" # vscode|pycharm
packages = ["io.micronaut", "jakarta"]
exclude-patterns = ["*ModuleInfo"]
destination-dir = "__pyronaut__/ide-stubs"
----

The default IDE target is `vscode`.
Stub generation is best effort; Pyronaut skips APIs that it cannot render cleanly and reports them in the stub generation report.

== VS Code

When `ide = "vscode"` and the project does not already own Pyright configuration, Pyronaut writes `.vscode/settings.json` with `python.analysis.extraPaths` pointing at the generated stub directory. When Pyronaut knows the Python executable or site-packages directory (from the project `.venv`, the `PYRONAUT_PYTHON_EXECUTABLE` or `PYRONAUT_PYTHON_SITE_PACKAGES` environment variables, or the matching `pyronaut.python.*` system properties), it adds the site-packages directory to `extraPaths` and sets `python.defaultInterpreterPath` as well.

If `pyrightconfig.json` or `[tool.pyright]` already exists, Pyronaut leaves the configuration user-managed and records that decision in the editor stub report.

For VS Code Test Explorer integration, see <<vscodeExtension,VS Code Test Explorer Extension>>.

== PyCharm

When `ide = "pycharm"`, Pyronaut writes a generated `.idea/pyronaut-editor-stubs.iml` module and registers it in `.idea/modules.xml`.
The generated module marks the stub directory as a source root without rewriting the main PyCharm project module.

== Refresh IDE state

Run `pyronaut install` after changing dependencies, source layout, or IDE stub settings.

Pyronaut caches generated stubs per classpath under `~/.pyronaut/ide-stubs` and shares them between projects on the same machine. Deleting `__pyronaut__/ide-stubs` makes the next install restore the stubs from that cache; delete the matching cache directory as well (or the whole of `~/.pyronaut/ide-stubs`) to force regeneration.

WARNING: `destination-dir` must point at a directory that Pyronaut owns. The generator replaces the directory's contents on every install and refuses to run when the directory contains files it did not generate.
