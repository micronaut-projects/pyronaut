= Getting Started

In this section you will learn how to define a minimal Pyronaut project and application.

== Create `pyproject.toml`

[source,toml]
----
[project] # (1)
name = "hello-pyronaut"
version = "0.1.0"
dynamic = ["scripts"]

[build-system]
requires = ["setuptools", "wheel", "tomli"]
build-backend = "setuptools.build_meta"

[tool.pyronaut]
repositories = ["mavenCentral"] # (2)

[tool.pyronaut.dependencies] # (3)
runtime = []
build = []
test = [
  "io.micronaut.pyronaut:micronaut-pyronaut-pytest",
  "io.micronaut.pyronaut:micronaut-pyronaut-requests"
]
----

<1> The basic project name, version etc. are defined using `pyproject.toml` conventions
<2> The `tool.pyronaut` namespace contains pyronaut specific configuration. Here we define the repository used to resolve Java modules.
<3> The `tool.pyronaut.dependencies` entry defines Java dependencies in specific scopes.

Versionless Micronaut coordinates are resolved from the configured Micronaut platform and core BOMs.
Add explicit versions for dependencies that are not managed by those BOMs.

== Add a Controller

Create `src/controllers.py`:

[source,python]
----
from micronaut.http.annotation import Get


@Get(value="/", produces="text/plain")
def index() -> str:
    return "Hello from Pyronaut"
----

== Add Application Configuration

Create `config/application.toml`:

[source,toml]
----
[micronaut.application]
name = "hello-pyronaut"

[micronaut.server]
port = 8080
----

== Run the Application

[source,bash]
----
pyronaut install
pyronaut process
pyronaut dev
----

`pyronaut dev` performs install and process preflight automatically, so after the first successful install this shorter form is normally enough:

[source,bash]
----
pyronaut dev
----

The application can then be called with:

[source,bash]
----
curl http://localhost:8080/
----

== Add a Test

Create `tests/test_controller.py`:

[source,python]
----
import pytest
import requests

from pyronaut.test import MicronautTest, micronaut_test_fixture


@pytest.fixture
def my_context(request):
    fixture = micronaut_test_fixture(request, MicronautTest())
    yield fixture
    fixture.stop()


@pytest.fixture
def client(my_context):
    return requests.with_context(my_context)


def test_index(client):
    response = client.get("/")
    assert response.status_code == 200
    assert response.text == "Hello from Pyronaut"
----

Run tests through Pyronaut so the Micronaut classpath and configured test engine are set up consistently:

[source,bash]
----
pyronaut test
----
