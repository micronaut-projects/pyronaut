Build a complete Pyronaut project with a `pyproject.toml`, an HTTP route, application configuration, and a test. Complete
the pages in this section in order for the project workflow.

Before you begin, complete the <<prerequisites,Prerequisites>>. They create the GraalPy virtual environment required by
the test workflow.

TIP: Use `pyronaut create demo` to generate this project, optionally with extra Micronaut features such as
`--features data-jdbc,mysql`. The following pages show how to create the files manually so you can see how they fit
together.

If you prefer direct-source mode, follow the <<fastApiTutorial,FastAPI tutorial>> instead.
