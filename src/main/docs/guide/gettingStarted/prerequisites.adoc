= Prerequisites

Pyronaut runs Python application code and Python tests on GraalPy, not on CPython.
`pyronaut setup` provisions the GraalPy version used by Pyronaut, and `pyronaut --version` shows it:

[source,bash]
----
pyronaut setup
pyronaut --version
----

If https://github.com/pyenv/pyenv#installation[pyenv] is installed, setup installs GraalPy with pyenv; otherwise it
downloads GraalPy into `~/.pyronaut/sdks`.

Change to your project directory and install the project:

[source,bash]
----
cd <project-dir>
pyronaut install
----

`pyronaut install` creates a GraalPy virtual environment in `.venv` and uses `pip` to install the Python dependencies
declared in `pyproject.toml` or `requirements.txt`, plus `pytest` when the project has Python tests.
Pyronaut uses this environment for application and test launches. A CPython-created environment cannot provide
packages to the embedded GraalPy runtime.

See <<usingPackagesJavaLibraries,Using Python Packages and Java Libraries>> for Python package compatibility and Java
library guidance.
