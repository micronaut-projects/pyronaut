= Prerequisites

Pyronaut runs Python application code and Python tests on GraalPy, not on CPython.
Install and select the GraalPy version used by Pyronaut with https://github.com/pyenv/pyenv#installation[pyenv]:

[source,bash]
----
pyenv install --skip-existing graalpy3.13-25.3.4.1
pyenv shell graalpy3.13-25.3.4.1
python --version
----

Change to your project directory:

[source,bash]
----
cd <project-dir>
----

Create and activate a GraalPy virtual environment. Then install `pytest` with the `pip` bundled in that environment:

[source,bash]
----
graalpy -m venv .venv
source .venv/bin/activate
python -m pip install pytest
python -m pytest --version
----

Create `.venv` with GraalPy. Pyronaut uses this environment for application and test launches. A CPython-created
environment cannot provide packages to the embedded GraalPy runtime.

See <<usingPackagesJavaLibraries,Using Python Packages and Micronaut Libraries>> for Python package compatibility and Micronaut
library guidance.
