= Prerequisites

Pyronaut tests run on GraalPy, not on a CPython installation.
Install and select the GraalPy version currently used by Pyronaut with https://github.com/pyenv/pyenv#installation[pyenv]:

[source,bash]
----
pyenv install --skip-existing graalpy3.12-25.2.4
pyenv shell graalpy3.12-25.2.4
python --version
----

From the project directory, create and activate a project virtual environment with GraalPy, then install `pytest` with the `pip` bundled in that environment:

[source,bash]
----
graalpy -m venv .venv
source .venv/bin/activate
python -m pip install pytest
python -m pytest --version
----

The `.venv` directory must be created with GraalPy.
Pyronaut automatically uses it for application and test launches, while a CPython-created environment cannot provide packages to the embedded GraalPy runtime.

See <<usingPackagesJavaLibraries,Using Python Packages & Java Libraries>> for Python package compatibility guidance and Java library usage.
